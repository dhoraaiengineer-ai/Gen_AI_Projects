# Benchmark: autorag_docs

## Purpose

Golden-dataset benchmark for evaluating AutoRAG's own retrieval and generation pipeline
against questions grounded in AutoRAG's own project documentation. Useful for regression
testing the pipeline against a corpus the team can verify by inspection, without needing
external test fixtures.

## Source Documents

`reference_context` and `source_document` fields in `generated/golden_dataset.json` cite
the real, live documentation in this repository rather than duplicating copies under
`source/` (duplicated copies drift out of sync with the real docs — this repo's own audit
history, see `.claude/docs/CHANGELOG.md`, has hit that exact problem before with the
archived v3.0 docs).

## Question Distribution

20 questions total. See `metadata.json` for the machine-readable distribution and
`reports/coverage_report.md` (generated by `evaluation/generators/export_dataset.py`) for
the full breakdown with pass/fail validation.

- Categories: Architecture, Retrieval, Ingestion, Evaluation, Agents, Deployment,
  Security, Monitoring (8 categories, matching the schema's `category` enum).
- Difficulty: 8 Easy / 8 Medium / 4 Hard.

## Citation Rules

`page_number` is `null` for markdown sources (no fixed pagination); `section` cites the
heading or code symbol (e.g. a function name) the answer is grounded in.

## Known Limitations

- All 20 questions carry `review_status: generated` — machine-generated from real,
  verified project documentation, but not yet human-reviewed. Per the dataset's own
  workflow (`generated` → `reviewed` → `approved`), a human reviewer should move each row
  to `approved` before this set is treated as an immutable benchmark for pipeline-version
  comparison.
- Sources are markdown/code files, not a fixed-pagination document — `page_number` is
  `null` throughout; retrieval evaluation should key on `section` instead.

## Generation Process

Hand-authored by an AI engineering agent (24-Jul-2026), grounded in direct reads of each
cited source file — not templated or fabricated. Validated against
`schema/golden_dataset.schema.json` via `jsonschema.Draft202012Validator` (0 errors, no
duplicate IDs).
