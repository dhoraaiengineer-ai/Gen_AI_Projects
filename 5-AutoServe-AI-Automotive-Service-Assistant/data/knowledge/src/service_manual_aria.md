## 7.1 Front brake pad replacement [safety]
Certified technician required. Op code OP-BRK-PAD-FR.
1. Raise and support the vehicle on approved stands. Remove the front wheels.
2. Remove the two caliper guide pin bolts and lift the caliper. Support it; do not let it hang on the brake hose.
3. Remove the pads and inspect the disc. Replace the disc if thickness is below the minimum in section 8.1.
4. Retract the piston, fit new pads with new clips, refit the caliper.
5. Tighten the guide pin bolts and wheel nuts to the torque values in section 8.1.
6. Pump the brake pedal until firm before moving the vehicle. Road test.

## 7.2 Misfire diagnosis (P0300–P0304)
Op code OP-DIAG-BASIC.
1. Read freeze-frame data. Note engine load, coolant temperature, and which cylinder is reported.
2. Swap the ignition coil of the misfiring cylinder with a neighbouring cylinder. Clear codes and road test.
3. If the misfire follows the coil, replace the coil (op code OP-IGN-COIL).
4. If the misfire stays on the same cylinder, inspect the spark plug and perform a compression test.
5. Check TSB-AR-2024-01 for 2021–2023 vehicles with rough idle on cold start.

## 7.3 Ignition coil replacement
Op code OP-IGN-COIL.
1. Disconnect the coil connector by pressing the locking tab.
2. Remove the coil retaining bolt and pull the coil straight up.
3. Fit the new coil, tighten the bolt to the torque value in section 8.1, and reconnect the connector until the lock clicks.

## 7.4 Evaporative system large leak (P0455)
Op code OP-DIAG-BASIC.
1. Check the fuel filler cap seal and that the cap clicks when closed.
2. Perform a smoke test of the EVAP system at the service port.
3. Inspect the purge valve and canister hoses for cracks.

## 8.1 Torque and wear specifications
| Item | Specification |
|---|---|
| Front caliper guide pin bolt | 28 N·m |
| Wheel nut | 110 N·m |
| Ignition coil retaining bolt | 8 N·m |
| Spark plug | 20 N·m |
| Front brake disc minimum thickness | 20.0 mm |
| Front brake pad minimum lining thickness | 2.0 mm |
