## 7.1 DPF forced regeneration (P2463)
Op code OP-DPF-REGEN.
1. Confirm the engine oil level is not above the maximum mark (oil dilution check).
2. Connect the Veloxa diagnostic tool and read the soot load value.
3. If the soot load is below the replacement limit in section 8.1, run the forced regeneration routine with the vehicle stationary, outdoors, and the exhaust clear of flammable material.
4. If the soot load is above the replacement limit, do not regenerate; replace the DPF.
5. Check TSB-TR-2024-02 for 2022–2024 vehicles used mainly for short trips.

## 7.2 Fuel return line clip inspection (recall RC-2025-01) [safety]
Op code OP-RC2501-INSPECT. Part VLX-FL-CLIP-02.
1. Work in a ventilated area with no ignition sources. Have a fire extinguisher available.
2. Inspect the fuel return line retaining clip at the fuel rail for correct seating.
3. Replace the clip with part VLX-FL-CLIP-02 regardless of condition.
4. Start the engine and check for leaks at the connection.

## 7.3 Glow plug circuit test (P0380)
Op code OP-GLOW-TEST.
1. Disconnect the glow plug connector and measure each glow plug resistance.
2. Compare with the specification in section 8.1. Replace any glow plug outside the range.
3. Check the glow plug relay supply with the ignition on.

## 7.4 EGR flow insufficient (P0401)
Op code OP-EGR-CLEAN.
1. Read live data for commanded and actual EGR valve position.
2. Remove the EGR valve and inspect for carbon build-up. Clean or replace.
3. Clear codes and perform the EGR adaptation routine.

## 7.5 Wheel balance and hub face cleaning
Op code OP-WHL-BAL.
1. Remove each wheel and clean the hub face and wheel mating surface of corrosion.
2. Balance all four wheels.
3. Refit wheels and tighten wheel nuts to the torque value in section 8.1 in a star pattern.

## 8.1 Specifications
| Item | Specification |
|---|---|
| DPF soot load replacement limit | 45 g |
| Glow plug resistance | 0.6–1.0 ohm |
| Wheel nut | 140 N·m |
| EGR valve bolts | 10 N·m |
